**CVE/SBOM verdict — per-component reasoning**

- **libtorrent-rasterbar 2.0.13 / 2.1.0** (pins verified in versions.lock; SHA-256 match re-confirmed by Main this session): GitHub published-advisory page for arvidn/libtorrent is EMPTY ("There aren't any published security advisories") and no 2024-2026 CVEs exist against rasterbar releases; historical CVEs (e.g. CVE-2016-7164) long predate 2.x. ⇒ **No relevant CVE.** Non-CVE delta: 2.0.14/2.1.1 hardening listed under SEC-2. Note: newer patch releases exist than the pins (2.0.14, 2.1.1).
- **OpenSSL 3.5.7** (LTS to 2030-04-08): enumerated the complete official 3.5-branch advisory list (openssl-library.org/news/vulnerabilities-3.5/, read in full 2026-08-22): CVE-2026-34180/34181/34182/34183/42764/42766/42767/42768/42769/42770 and the Jan-2026 batch incl. high-severity CMS issues are all **fixed in 3.5.7** (affected ranges end "before 3.5.7"). Exactly one CVE exceeds the pin: **CVE-2026-14456** (Low, QUIC-server incoming-channel backlog DoS, fixed 3.5.8) — QUIC is unused in this integration (static OpenSSL consumed by libtorrent for client TLS trackers/SSL torrents/MSE-PE only) ⇒ **not relevant**. Config surface reduction holds (`no-shared no-legacy no-apps no-docs no-tests`).
- **Boost 1.91.0**: used strictly header-only (Asio/System/Config/Pool/CRC per SBOM §1). Only notable recent CVE is CVE-2026-11460 (**Boost.Serialization** — not used); 2024 Shielder/OSTIF audit findings were Beast/JSON (not used); no Asio/System CVEs in window. ⇒ **No relevant CVE.**
- **Licenses**: BSD-3-Clause / Apache-2.0 / BSL-1.0 (+Zlib via bundled ed25519) — permissive, no copyleft; attribution maintained (SBOM §3). WebTorrent/libdatachannel (MPL-2.0) explicitly excluded by build flag (build.sh:261-265).

**Clean surfaces (one-line basis)**

- **XPC peer verification**: both sides install a frozen SecRequirement (`identifier com.torrentino.app[/engine-agent] and anchor apple generic and certificate leaf[subject.OU] = 438UQRF7JV`) via `setCodeSigningRequirement` BEFORE resume/payload decode (AgentRuntime.swift:543-563, EngineClient.swift:349-351, TorrentinoXPCProtocol.swift:83-92); missing authorizer fails closed (invalid expression ⇒ reject); health `[String:Any]` reply class-whitelisted to NSDictionary/NSString/NSNumber; per-connection exported forwarding objects scope event sinks so a short-lived CLI connection cannot hijack the GUI subscriber (AgentService.swift:44-77, 205-260).
- **Untrusted XPC payloads**: single `sendCommand(Data)` lane takes plist-safe Data; malformed JSON ⇒ typed `invalidPayload`; kind/shape enforced by `envelope.validate()`; command-lane concurrency capped at 64 (`AgentHealthLane.commandLimit`); degraded-mode admission allows only hello/prepareForQuit/restart/exportDiagnostics.
- **Idempotency/replay**: bounded registries (1024 commit-add results, 256 removal tokens, 64MiB pending-inspection cap); tracker-edit key reuse with different topology rejected; creator idempotency keys single-use ("cannot mint a second authoritative operation"); durable removal outcomes replay identically (TransferCoordinator.swift:101-146, 998-1001, 2504-2509, 2817-2860, 3448-3450).
- **Instance-change snapshot semantics**: `HelloResponse.instanceID` changes every agent restart and the contract mandates full discard+refetch; UI additionally refetches on revision gaps and `snapshotRequired` (Handshake.swift:25-29, TorrentListViewModel.swift:11-24, 317-319, 433-434).
- **Bencode/magnet/metainfo parsers**: bencode bounded (16 MiB input, depth 64, digit-count caps, leading-zero/`-0` rejection, sorted unique dict keys, whole-input consumption — BencodeParser.swift:69-218); magnets capped 8 KiB with strict btih hex/base32 and http(s)/udp tracker allowlist (MagnetParser.swift:62-127); metainfo validates every relative path through PathValidator, rejects duplicate post-normalization paths (catches NFC collisions), enforces v1/v2 hybrid order+size equality, pieces==ceil(size/pieceLen)*20, 10k file cap, overflow-guarded totals (Metainfo.swift:196-306, 430-545).
- **PathValidator**: pure, I/O-free; rejects absolute, drive-colon, `..`/`.` components, backslash, null bytes, empty/reserved/trailing-dot-space components; caps 512×255/4096; NFC normalization (PathValidator.swift:19-116). Materialization-time symlink/TOCTOU defense exists on the mutation paths (RemovalManifest.verifyChain lstat walk + O_NOFOLLOW leaf identity, TrashService, MoveStorageRecovery lstat evidence).
- **Creator inspect/commit (ADR-016/017)**: descriptor-anchored `openat` walk from "/" with `O_NOFOLLOW` per component, leaf-absence via `fstatat(AT_SYMLINK_NOFOLLOW)`, `F_FULLFSYNC` durability, verification read capped at maxTorrentFileBytes, plan superseded on new inspection (CreatorPlanStore.swift:100-330).
- **HTTP source fetcher**: http(s) only, ≤5 redirects with redirect-scheme re-check, 10 MiB cap enforced on both advertised length and cumulative stream, content-type allowlist, 30 s deadlines, ephemeral session, per-fetch locked delegate, never writes to disk itself (HTTPSourceFetcher.swift:25-280).
- **Keychain use**: single fixed service/account generic-password item, `AfterFirstUnlock`, delete-before-add, Security I/O off the main thread; no other secret stores found (grep: kSecClass only in KeychainStore.swift); `ProxyConfiguration.description/debugDescription` redact the password (State.swift:222-228).
- **Diagnostics export (new surface)**: destination must be nonexistent-or-empty (fail-closed pre-write), every entry re-passes the compiled redactor, settings projection is field-enumerated (proxy password has no representation), mid-write failure rolls back written files and surfaces rollback failures, FailpointInjector production-noop, export admitted in degraded mode (TransferCoordinator.swift:763-886; hostile-vector parity tests in WP13DiagnosticsSecurityTests incl. escaped-quote/newline secrets and reason-field redaction).
- **DoS/queue bounds**: event bus bounded (256 pending, one coalesced batch per slow sink, overflow flagged — TransferEventBus.swift:16-44); command lane 64; pagination clamped server-side (≤1000/page); CrashLoopGuard keeps a bounded 5-min/3-start history file at 0600.

**Residual risks (accepted, no finding)**

- Redactor mirror (`Agent/RedactedLogFileManager.swift`, intentionally not a build member) drifts only if retuned without the byte-identical lockstep XCTest — coverage judged adequate (test executes the mirror's declared rules and compares outputs).
- Export destination empty-dir check has a same-user TOCTOU window (symlinked empty dir followed); within the single-user threat model; rollback discipline verified.
- Magnet `ws=`/`as=` values lack the `tr=` scheme allowlist (bounded by the 8 KiB magnet cap; unusable schemes rejected downstream by libtorrent) — Info-level inconsistency only.
- Debug builds: app-side peer checks skip (`PeerValidation.isEnforcementActive == false`) while the agent ALWAYS enforces the Developer-ID expression — asymmetry fails closed; TestProfile/dev flows rely on their signing setup.
- OpenSSL pin trails LTS by one Low patch (3.5.8 / CVE-2026-14456, QUIC unused); bump opportunistically at the next pin review together with SEC-2.
- Graphify map 11 days stale at engagement time; did not rebuild (out of scope); all graph-derived leads verified against live source.
